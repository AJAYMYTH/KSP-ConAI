# 🚔 KSP-ConAI — Crime Intelligence Platform

Official repository for the **Karnataka State Police (KSP) Crime Intelligence & Suspect Profiling Platform**.

---

## 📂 Repository Structure

- [`frontend/`](./frontend) — Astro.js + React 18 Crime Intelligence Copilot web application.
- [`docs/`](./docs) — System Architecture, PRD, TRD, & Deployment Documentation.

---

## 🚀 Quick Start (Frontend)

To run the frontend web application locally:

```bash
cd frontend
npm install
npm run dev
```

The application will be accessible at [http://localhost:4321/app](http://localhost:4321/app).

For full details on frontend architecture, component libraries, scripts, and environment configuration, refer to the [Frontend README](./frontend/README.md).
